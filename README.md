# Artem Control Center

Персональная сенсорная панель Артёма для умного дома, мониторинга сервисов, календаря, задач и безопасного запуска заранее разрешённых действий.

## Зафиксированные продуктовые решения

- **UI runtime:** Chromium в полноэкранном kiosk-режиме.
- **Frontend:** React + TypeScript + Vite.
- **Backend:** локальный Panel Agent; рекомендуемый стек — FastAPI.
- **Первый хост:** Windows на Samsung Notebook 9 Pro 13" (NP940X3M).
- **Целевая ОС:** Linux после проверки тачскрина, поворота, сна, Wi-Fi и Android-приложения.
- **Интерфейс:** touch-first, но пригодный для обычной работы мышью и клавиатурой.
- **Погода:** обязательный элемент главного экрана.
- **Темы:** обязательные отдельные дневная и ночная темы с автоматическим переключением и ручным override.
- **Motion design:** выразительные, плавные и функциональные анимации — обязательная часть продукта, а не необязательная полировка.
- **Home Assistant:** текущий удалённый HA остаётся основным источником состояния и автоматизаций.
- **Offline/failover:** локальный edge-контур выполняет только заранее выбранные критичные сценарии; полноценный резервный HA хранится как warm standby и не работает параллельно с основным без явного переключения.
- **Безопасность:** браузер не получает SSH-ключи, административные токены или возможность выполнять произвольные команды. Все действия проходят через allow-listed backend actions.

## Главные разделы панели

1. **Overview** — часы, дата, погода, ближайшие события, задачи, состояние дома и общий статус сервисов.
2. **Home** — кофемашина, чайник, свет, розетки, климат, сцены и критичные локальные действия.
3. **Services** — health, latency, incidents, deployment state и безопасные restart/control actions.
4. **Calendar & Tasks** — календарь iPhone/iCloud/Google/Exchange через адаптер источника и задачи TickTick.
5. **Automations** — запуск n8n, backup, checks и других заранее описанных workflows.
6. **Apps** — запуск Android-карты лояльности и других полноэкранных приложений.
7. **System** — питание, сеть, батарея, температура, диск, журналы действий и переход на обычный рабочий стол.

## Базовый принцип

Ноутбук является красивым интерфейсом, локальным edge-контроллером и пунктом наблюдения, но не единственной точкой, от которой зависят дом, серверы или доступ к данным.
