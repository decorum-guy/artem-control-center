# Artem Control Center — план редизайна

Nov 17, 2026 · @Art

## Как пользоваться

Ниже один промпт: агент по нему сам пишет в репозиторий спецификацию и дорожную карту редизайна и сразу кодит по этапам.

- Откройте сессию агента в корне artem-control-center и вставьте блок «Промпт» целиком.

- За первую сессию агент пишет документы, собирает фундамент (токены, шрифты, компоненты) и новую оболочку, затем останавливается и показывает скриншоты «до/после».

- Каждую следующую сессию начинайте фразой: «Продолжай по docs/design/control-center-v3/ROADMAP.md, следующий этап».

- Новый вид включается отдельным флагом сборки. На Samsung он попадёт только после вашего решения, старый вид остаётся запасным.

Характер дизайна задан в разделе 3 промпта: тёмная «кабина», холодный циан и янтарь для тепла. Если хотите другой характер, поменяйте этот раздел до запуска.

## Что не так сейчас

Я запустил панель локально на тестовых данных с production-флагами и просмотрел все 12 разделов в альбомной и портретной раскладке. Функционально она зрелая, а выглядит как плоская серая админка.

- Все карточки одинаковые графитовые прямоугольники: нет глубины, главного элемента и акцентов.

- Заголовки страниц оформлены по-разному почти на каждом разделе, в Календаре заголовок вообще справа.

- Системные выпадающие списки и ползунки, emoji в Кофейном дневнике, текстовые значки вместо иконок.

- В шапке обрезаются подписи: «Преимущест…», «Доступ недосту…».

- Погода: слабый главный блок и нечитаемые значки почасового прогноза.

- Кофемашина: фото на плоской карточке и тонкая полоска прогресса вместо выразительного состояния.

- Пустые состояния и экран загрузки показаны голым текстом.

- В коде 32 файла стилей на 10,5 тыс. строк, цветовые токены продублированы 4 раза, в styles.css 215 цветов прописаны напрямую.

Ограничения, которые редизайн обязан сохранить: старый слабый ноутбук с 8 ГБ памяти, сенсорные цели от 48 px, дневная и ночная темы, режимы уменьшенного движения, никаких выдуманных данных.

   Чужие незакоммиченные изменения не трогай.
2. Доступ. Проверь, можешь ли ты пушить ветки и открывать PR. Если нет, не останавливайся:
   работай локальными коммитами и в отчёте напиши, что нужно запушить вручную.
3. Окружение. Node от 20.19, Python 3.12 (как в CI; на 3.13 тоже запускается).
   Выполни npm run setup. Для скриншотов поставь Chromium через npm run install:browsers
   или используй системный Chrome.
4. Запуск. Панель поднимается только на тестовых данных: npm run dev:fixtures с переменными
   из webServer.command в playwright.config.ts. Никакого SSH, production, реальных устройств

6. Ветки. main не трогай. На каждый этап отдельная ветка redesign/v3-stage-<N>. Этапы не
   мержатся, поэтому ветку следующего этапа создавай от ветки предыдущего. PR открывай как
   draft, с базой на предыдущий этап. Merge и deploy не делай.
7. Порядок. До первой строки кода прочитай документы из раздела 1 задачи и запиши план в
   docs/design/control-center-v3/ROADMAP.md. Дальше иди по этапам из раздела 6 задачи.
8. Вопросы. Не останавливайся ради уточнений по мелочам: принимай разумное решение сам и
   записывай его в ROADMAP.md в список «Решения, принятые без владельца». Останавливайся
   только при конфликте задачи с кодом или тестами и там, где задача прямо велит остановиться.
9. Проверка себя. После каждого этапа открой собственные скриншоты и сравни с разделом 3
   задачи. Если экран выглядит как прежняя серая админка с перекрашенными цветами, этап не
   готов: доработай до сдачи.

## 3. Визуальное направление V3: «Кабина»

Образ: приборная панель космического корабля ночью. Глубокий тёмный фон, тонкие световые
линии, крупные лёгкие цифры, приборы-кольца. Главный принцип: свет означает энергию.
Светится только то, что включено, живо или выполняется прямо сейчас. Выключенное,
устаревшее и недоступное выглядит погасшим. Так футуристичность работает на чтение
состояния и не превращается в украшение.

### 3.1 Ночная тема (основная). Стартовые значения токенов

  --cc-canvas #05070c            --cc-rail #0a0e16
  --cc-surface-1 #0d121c         --cc-surface-2 #121927
  --cc-interactive #182132       --cc-hover #1e2a3f        --cc-pressed #141c2b
  --cc-border rgb(148 184 255 / 14%)   --cc-border-strong rgb(148 184 255 / 28%)
  --cc-divider rgb(148 184 255 / 8%)
  --cc-text #eaf2ff   --cc-text-secondary #a9b8d0   --cc-text-muted #7385a0
  --cc-text-disabled #4d5b73
  --cc-accent #35d6ff (энергия)   --cc-accent-strong #7ae7ff   --cc-on-accent #031018
  --cc-focus #9bedff
  --cc-heat #ffb454 (тепло: кофе, чайник, нагрев)
  --cc-success #3ee6a5   --cc-warning #ffc15a   --cc-danger #ff6b7a
  --cc-stale #c9a878     --cc-offline #8794aa   --cc-unavailable #8e8698
  --cc-uncertain #9aa9ff
  Фоны и рамки статусов выводи через color-mix: фон 10-12% цвета статуса поверх
  surface-1, рамка 35%.
  --cc-glow-accent: 0 0 0 1px rgb(53 214 255 / 35%), 0 0 24px rgb(53 214 255 / 28%)
  По той же формуле --cc-glow-heat, --cc-glow-success, --cc-glow-warning, --cc-glow-danger.

Фон приложения: один неподвижный слой (position: fixed, без анимации) из трёх частей:
холодное радиальное пятно слева сверху rgb(56 189 248 / 10%), тёплое справа снизу
rgb(245 166 35 / 6%), точечная сетка 24 px rgb(255 255 255 / 4.5%). Поверх лёгкая виньетка.

### 3.2 Дневная тема

Светлая холодная «лаборатория», не перекраска ночной темы.
  --cc-canvas #eef2f7   --cc-surface-1 #ffffff   --cc-surface-2 #f5f8fc
  --cc-interactive #e8eef6   --cc-border rgb(15 40 80 / 14%)
  --cc-text #0c1626   --cc-text-secondary #42526b   --cc-text-muted #5f6f88
  --cc-accent #0079a8   --cc-on-accent #ffffff   --cc-heat #b86a00
  --cc-success #0e8a5f   --cc-warning #9a6200   --cc-danger #c7334a
Свечения в дневной теме нет: токены --cc-glow-* превращаются в мягкую цветную тень
(0 6px 20px, 18% цвета). Точечная сетка тёмная, 5%.

Все значения стартовые. Можно подстраивать, но текст обязан иметь контраст от 4.5:1,
значимые линии и иконки от 3:1, в обеих темах. Проверь расчётом и запиши в спецификацию.

### 3.3 Типографика

- Текст и цифры: Manrope Variable. Крупные цифры (время, температура, состояние прибора)
  лёгким начертанием 300-400, tabular-nums.
- Технические подписи: JetBrains Mono Variable. Kicker-метки, время обновления, единицы,
  идентификаторы, счётчики. Kicker: 11-12 px, uppercase, letter-spacing .12em.
- Шрифты лежат в репозитории как woff2 с кириллицей (лицензия OFL), без CDN,
  font-display: swap, суммарно до 250 КБ. Проверь наличие кириллицы до подключения.
  Запасной стек оставь текущий системный.
- Шкалу размеров из V2 сохрани, поменяй характер: время в шапке 40/44 weight 300,
  температура погоды 72/72 weight 300, состояние прибора 28/32 weight 500.

### 3.4 Поверхности и форма

- Панель: фон surface-1 плюс вертикальный градиент rgb(255 255 255 / 4%) -> 1%, рамка
  1 px --cc-border, сверху внутренний блик 1 px rgb(255 255 255 / 6%).
  Это имитация стекла без backdrop-filter.
- Три уровня: обычная панель; активная панель (устройство включено или идёт действие):
  рамка цвета состояния 45% и соответствующий --cc-glow-*; hero-панель (не больше одной
  на экран): дополнительно угловые HUD-скобки 12 px и мягкое цветное пятно внутри.
- Радиусы: control 10, surface 14, zone 16, sheet 22 px.
- Разделители: линия 1 px с затуханием к краям.
- Иконки: один набор линий в icons.tsx, толщина 1.5, размер 22 в навигации и 20 в
  контролах. Дорисуй недостающие и замени все emoji и текстовые глифы.

### 3.5 Компоненты (общие примитивы, один раз для всех экранов)

- PageHeader: единый для всех маршрутов. Kicker моноширинным, заголовок, описание,
  справа действия. Заменяет разнобой RouteHeader и локальных заголовков.
- Button: primary (заливка accent, тёмный текст, glow), secondary (контур), ghost,
  danger; высоты 48 и 56; при нажатии scale .98 и короткая вспышка.
- StatusChip: точка, иконка и текст. Точка светится цветом статуса. Пульсирует только
  при выполняющемся действии.
- Select: свой контрол вместо нативного select. Список опций открывается в общем Sheet,
  строки от 56 px. Для 2-4 вариантов используй Segmented.
- Switch, Slider (громкость, яркость, лента), Stepper, Segmented: свои, с целями 48 px.
- RingGauge: SVG-кольцо для прогресса и значений. Рисует только реальные данные.
  Неизвестная длительность показывается стадиями без процентов.
- EmptyState, Skeleton, BootScreen, ErrorState: с линейной иконкой и kicker-меткой.
- Sheet, Dialog, NoticeCenter, PIN-клавиатура, подтверждения: стиль панели, крупные
  клавиши. Логика, фокус-ловушки и сила подтверждения остаются прежними.

### 3.6 Фирменные элементы

1. Кофемашина, главный прибор. Изображение стоит на тёмном «пьедестале» с пятном света
   под ним, вокруг RingGauge. Выключена: кольцо погашено. Включение и разогрев: кольцо
   цвета heat заполняется по реальному прогрессу, пар сдержанный. Готова: полное кольцо
   success и одна мягкая вспышка. Работает слишком долго: кольцо warning пунктиром, без
   мигания. Stale и unavailable: пунктир без цвета. Контракт visualAsset в манифесте и
   правила AGENTS.md, раздел 5, остаются в силе.
2. Шапка-телеметрия: крупное лёгкое время, дата моноширинным, справа чипы погоды,
   состояния систем и доступа. Подписи не обрезаются: сначала сокращается дата, потом
   чип переходит в короткую форму.
3. Навигация: активный пункт получает световую полосу слева и мягкую подсветку фона,
   иконка цвета accent. Логотип ACC в виде кольца-эмблемы.
4. Чайник, кондиционер, лента, станция: температура и уставка крупной цифрой с дугой
   RingGauge; включённый прибор получает активную панель.
5. Погода: фон главного блока зависит от условия и isDay, действуют правила компоновщика
   из V2 (не больше двух движущихся слоёв, плитки без шва). Новый набор глифов 32 px.
6. Jarvis: световой орб со всеми состояниями из JarvisOverlay.tsx (idle, listening,
   transcribing, submitting, speaking, ready, error). Только CSS и SVG.
7. Экран загрузки: эмблема-кольцо и скелеты вместо строки «Загружаем данные…».

### 3.7 Движение (только в motion-full)

- Смена маршрута: fade и подъём на 8 px за 220 мс.
- Первое появление экрана: каскад панелей с шагом 40 мс, не больше 6 шагов, один раз.
- Нажатие 100 мс. Sheet и Dialog: сдвиг и fade за 280 мс.
- Смена состояния прибора: кольцо и цвет панели переходят за 400 мс.
- Живая точка пульсирует с периодом 2.4 с и только при выполняющемся действии.
- Смена темы: плавный переход токенов за 300 мс, без белой вспышки.
- Easing везде cubic-bezier(.2,.8,.2,1). Предупреждения не мигают.

### 3.8 Бюджет производительности

- Анимировать только transform и opacity. Нельзя анимировать box-shadow, filter,
  background-position и свойства раскладки. Пульс свечения делай через opacity
  псевдоэлемента с готовой тенью.
- backdrop-filter не использовать. Исключение: подложка Sheet в motion-full, если замер
  на целевом железе не показывает просадки.
- Вне погоды не больше двух бесконечных анимаций на экране.
- В reduced, low-performance, battery-saving и при document.hidden бесконечные анимации
  остановлены, свечение статично, информация та же.
- Без новых runtime-зависимостей: никаких UI-библиотек, Tailwind, CSS-in-JS и библиотек
  анимации. Только CSS, SVG, React.
- coffee-machine.png (2,5 МБ) и station-mini-2.png (0,7 МБ) получают оптимизированные
  webp-варианты под реальный размер показа, как уже сделано для Overview.
- В отчёте каждого этапа укажи изменение размера бандла и CSS.

## 4. Как встраивать в код

- Новый флаг сборки VITE_V3_VISUAL_SKIN, по умолчанию false. При true на .app ставится
  класс skin-v3, на html атрибут data-skin=v3. Все новые значения токенов и новые стили
  живут под этим классом. Без флага панель выглядит как сейчас, существующие тесты
  остаются зелёными. В production-профиль флаг не добавлять: это отдельное решение

## 5. Чего делать нельзя

- Менять API, контракты, маршруты, feature gates, политику доступа, PIN и подтверждения,
  схему раскладки, тексты каталога, data-testid, aria-атрибуты, порядок фокуса.
- Показывать выдуманные данные, проценты, графики или декоративные метрики.
- Кодировать статус только цветом или свечением: текстовая метка обязательна.
- Делать цели меньше 48 px или прятать действия за hover.
- Трогать внешние проекты, production, секреты; делать merge и deploy.
- Украшать ради украшения: каждое свечение обязано означать состояние.
